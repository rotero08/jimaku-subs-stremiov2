Jimaku Kaiyo Subs

Japanese subtitles from the Jimaku community, inside Stremio. Works with Kitsu, MyAnimeList, AniList and IMDb titles, and with ZIP files.

1Your Jimaku API key

Jimaku is free, but its API needs an account. Open your account page, create a key and paste it here.

2Options

ASS subtitles (a styled format that not every app can show)

3Install

Install in Stremio Stremio Web

This server is not on https, so the one-click button is off. In Stremio, open Addons, paste the link above into the search box and press Install.

The link contains your key. Treat it like a password: do not post it or share it.

If nothing shows up, and your privacy
  • Nothing appears? Jimaku may not have that episode yet. Check jimaku.cc.
  • Privacy. This server does not store your key or what you watch. The key travels inside the addon link, which Stremio keeps with your addons; requests use it only to ask Jimaku for subtitles.
