3Install

Install in Stremio Open in Stremio Web

This server is not on https, so the one-click button is off. In Stremio, open Addons, paste the link above into the search box and press Install.

The link contains your key. Treat it like a password: do not post it or share it.

How it finds subtitles, and what to do when nothing shows up
  • Matching. For anime from the Kitsu addon (or MAL, AniList, AniDB catalogs) the exact title is looked up by its AniList id. For IMDb-based catalogs it uses the TMDB id, and falls back to the title.
  • Best first. If the file you are playing has a release name (for example [SubsPlease] … (1080p)) the subtitle made for the same release is listed first: it is the one that stays in sync.
  • Nothing appears? Jimaku may not have that episode yet. Check jimaku.cc. Some episodes are only available inside ZIP files, which Stremio cannot read.
  • Privacy. This server does not store your key or what you watch. The key travels inside the addon link, which Stremio keeps with your addons; requests use it only to ask Jimaku for subtitles.
